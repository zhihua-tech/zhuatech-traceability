# 产品全链路追溯系统企业能力

## 领域覆盖

- **批次管理**：统一原料、半成品和成品批次规则
- **序列号管理**：管理单品身份、包装层级和状态
- **产品谱系**：关联投入批次、工序、设备和产出
- **生产事件**：采集投料、加工、返工和报废事件
- **质量记录**：绑定检验、放行、不合格和处置结果
- **物流追踪**：记录库位、装箱、发运和签收节点
- **销售去向**：连接订单、客户、区域和交付批次
- **召回管理**：模拟与执行正向、反向召回
- **追溯审计**：检查链路完整性、时效和数据异常

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对产品全链路追溯系统关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `MES`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
